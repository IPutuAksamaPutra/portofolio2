# Personal Portfolio

Website portfolio pribadi yang dibuat menggunakan **Next.js**, **TypeScript**, dan **Tailwind CSS**.

## Tech Stack

- Next.js
- TypeScript
- Tailwind CSS
- Framer Motion

## Features

- Responsive Design
- About
- Skills
- Projects
- Experience
- Contact

## Installation

```bash
git clone https://github.com/username/portfolio.git
cd portfolio
npm install
npm run dev
```

Buka di browser:

```
http://localhost:3000
```

## Build

```bash
npm run build
```
